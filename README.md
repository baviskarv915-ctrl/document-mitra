# Document Mitra

## Your One-Stop Solution for Government Document Services

Document Mitra is a simple, mobile-friendly portal that provides easy access to information about various government documents and services in India.

### 🎯 Features

- **Aadhaar Support**: Information about obtaining, updating, and downloading e-Aadhaar
- **PAN Services**: Guide to applying for and managing PAN
- **Income Certificate**: Details about applying for income certificates via Maharashtra Aaple Sarkar
- **Caste Certificate**: Information about obtaining caste certificates via Maharashtra Aaple Sarkar
- **Domicile/Residence Certificate**: Guide for domicile certificate applications via Maharashtra Aaple Sarkar
- **Official Links**: Direct links to all official government portals
- **Mobile-Friendly Design**: Fully responsive layout for all devices
- **Simple Interface**: Easy-to-navigate portal with clear information

### 📱 Responsive Design

- Desktop view: Multi-column layouts for optimal viewing
- Tablet view: Adaptive grid layouts
- Mobile view: Single-column responsive design with mobile menu

### 🛠️ Technology Stack

- HTML5
- CSS3 (with Flexbox and CSS Grid)
- Vanilla JavaScript
- Font Awesome Icons

### 📋 Services Included

1. **Aadhaar**
   - e-Aadhaar download
   - Aadhaar update information
   - Links to UIDAI portal

2. **PAN**
   - PAN application details
   - e-PAN services
   - TIN-NSDL portal links

3. **Income Certificate**
   - Application process
   - Required documents
   - Maharashtra Aaple Sarkar portal access

4. **Caste Certificate**
   - Eligibility criteria
   - Document requirements
   - Maharashtra Aaple Sarkar portal access

5. **Domicile/Residence Certificate**
   - Application steps
   - Document checklist
   - Maharashtra Aaple Sarkar portal access

### 🚀 Getting Started

1. Open `index.html` in your web browser
2. Browse through different services
3. Click on "Learn More" for detailed information
4. Click on "Official Site" to access government portals
